# YOLO RKNN 部署整理包

本目录整理了 2026-07-28 完成的钢珠 YOLO 模型训练、ONNX 导出、INT8 RKNN 转换、香橙派部署和性能测试文件。

## 最终部署文件

将下面两个文件上传到香橙派 `/home/orangepi/`：

```text
04_香橙派部署/camera_detect.py
06_模型/final/ball_best_int8_split.rknn
```

香橙派运行：

```bash
cd /home/orangepi
python3 camera_detect.py
```

## 新模型转换顺序

```text
01_训练_PT/train_ball_pt.py
-> 02_ONNX导出与拆分/export_onnx.py
-> 03_RKNN转换/prepare_ball_calibration.py
-> 02_ONNX导出与拆分/split_yolo_output.py
-> 03_RKNN转换/convert_ball_int8_split.py
-> 04_香橙派部署/camera_detect.py
```

## 模型说明

| 文件 | 说明 |
|---|---|
| `06_模型/source/best.pt` | 原始训练模型 |
| `06_模型/source/best.onnx` | 原始单输出 ONNX |
| `06_模型/final/ball_best_split.onnx` | boxes/scores 分离后的 ONNX |
| `06_模型/final/ball_best.rknn` | FP16 RKNN 回退模型 |
| `06_模型/final/ball_best_int8_split.rknn` | 最终推荐 INT8 RKNN 模型 |

## 不要用于正式部署

`06_模型/experimental/` 中的普通单输出 INT8 模型会将小于 1 的置信度量化为零，只用于保留问题复现和对比结果。

## 已验证性能

```text
INT8 单核：39.39 FPS
INT8 双核：76.68 FPS
INT8 三核：106.75 FPS
OpenCV V4L2 摄像头：42.20 FPS
GStreamer 摄像头：88.48 FPS
```

正式运行时以画面上的 `E2E FPS` 和 `Lat` 为端到端指标，不要把摄像头 `CAM` 帧率或三核 `NPU` 吞吐当作端到端帧率。
