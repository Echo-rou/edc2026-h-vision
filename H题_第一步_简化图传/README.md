# H 题第一步：最简图传和电脑录像

这一版只完成题目要求第 1 项：

- 摄像头和香橙派固定在小车上。
- 香橙派创建 Wi-Fi 热点并发送实时画面。
- 笔记本电脑放在环形线路外，通过浏览器显示和保存视频。
- 网页只有一个保存按钮：第一次点击开始，第二次点击结束并下载，再次点击又开始。
- 不安装服务，不开机自启。每次使用时手动运行。

## 1. 复制到香橙派

在 Windows PowerShell 中执行，将 IP 换成香橙派当前地址：

```powershell
scp -r "H题_第一步_简化图传" orangepi@香橙派当前IP:/home/orangepi/
```

## 2. 在香橙派运行

```bash
cd "/home/orangepi/H题_第一步_简化图传"
bash run.sh
```

保持终端开启。程序结束时按 `Ctrl+C`。

## 3. 电脑连接并录像

1. 电脑连接 Wi-Fi：`BallVision`
2. 密码：`12345678`
3. Edge 或 Chrome 打开：`http://192.168.5.1:8080/`
4. 测试开始时点击“开始保存”
5. 测试结束时再次点击“结束并保存”
6. 视频会进入电脑的下载目录
7. 下一次测试再点击同一个按钮即可

浏览器如果询问是否允许下载，请选择允许。建议正式测试前录制一段 10 秒视频，
停止后确认能够从电脑下载目录正常回放。

## 4. 摄像头安装要求

题目要求回传画面覆盖整个 25 cm 摆杆，能清晰看到钢球轨迹并判定位置。因此：

- 摄像头固定在凹槽正上方，不要只拍中间区域。
- 画面中同时保留左右端、中心 O 点和刻度线。
- 固定架不能在小车运动时明显晃动。
- 调整曝光，避免钢球反光变成白斑。

## 5. 简单排错

查看摄像头节点：

```bash
v4l2-ctl --list-devices
```

摄像头不是 `/dev/video0` 时：

```bash
bash run.sh --camera 1
```

只测试画面和热点，不运行钢球识别：

```bash
bash run.sh --no-detect
```

如果电脑打不开网页，先在香橙派运行：

```bash
curl http://127.0.0.1:8080/health
```

正常时会返回包含 `"status"` 的一行 JSON。
